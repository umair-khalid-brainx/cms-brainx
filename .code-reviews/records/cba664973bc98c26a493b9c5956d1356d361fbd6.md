## Summary

Stack: React (admin/, Vite + React 19). Adds a reusable phone layout (`stack-table`, ≤720px) in `admin/src/ui.css`
that turns each table row into a card: `.stack-primary` is the card heading, `data-label` captions every other
cell, `.stack-actions` sits on a bottom line. Applied to the Review queue, Team (members + invites) and Content
types tables. Specificity was checked against the page stylesheets that load after `ui.css` (`.pages-table`,
`.team-table`, their dark-mode rules, `.pages-row-actions`, `.team-row-actions`). The doubled
`table.stack-table.stack-table` and the `tbody td` selectors beat all of them, so the cards render as intended in
both schemes. No correctness or security problems.

Re-review (2026-10-15T07:38:14Z): the Team-only rules now live in `pages/TeamPage.css`, in a `@media (max-width:
720px)` block. The redundant dark-mode backgrounds are gone from `ui.css`. Two of the three Low findings are fixed.
The duplicated `.pl-table` base is still open.

Not findings, for awareness: `RedirectsPage` and `TaxonomyPage` still use a plain `pages-table` without
`stack-table`, so they keep the old wide layout on phones. Pages list keeps its own `.pl-table` version.
`docs/WORKLOG.md` / `docs/BACKLOG.md` have no entry for this change yet.
